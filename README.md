# Sales Data Analysis using Python & SQL

Analyzed sales data using Python and SQLite to calculate revenue and evaluate product performance.

## Key Results
- Total orders: 10 | Unique products: 5
- Total quantity sold: 44
- Total revenue: Rs. 2,31,200

## Skills Used
- SQL: aggregation, GROUP BY, ORDER BY
- Python (sqlite3), Jupyter Notebook

## How to Run
1. Open sales_analysis.ipynb in Jupyter Notebook
2. Run all cells (Kernel → Restart & Run All)
